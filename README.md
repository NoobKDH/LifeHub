# LifeHub 🌟

생산성 향상을 위한 올인원 데스크톱 애플리케이션

![Version](https://img.shields.io/badge/version-1.1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ 주요 기능

### 📝 할 일 관리
- 할 일 추가/삭제/완료
- **날짜별 필터링** (전체/오늘/내일/1주일 후/마감임박) ⭐ NEW
- 우선순위 설정 (높음/보통/낮음)
- 카테고리별 분류 (개인/업무/쇼핑/건강)
- 진행률 시각화

### 🎯 습관 트래커
- 일일 습관 체크
- 연속 달성 일수 표시
- 완료율 시각화

### 📅 일정 관리
- 월간/주간/일간 캘린더 뷰
- 날짜/시간/장소 설정
- 반복 일정 (매일/매주/매월)
- 카테고리별 색상 구분
- 일정 검색 및 필터링
- **삭제 확인 모달** ⭐ NEW

### 📄 메모
- 제목/내용/태그 작성
- 메모 목록 관리

### 🎨 기타
- 🌓 다크/라이트 모드
- 💾 자동 저장 기능
- 🔍 일정 검색

## 🚀 시작하기

### 필수 요구사항
- Node.js 18 이상

### 설치
\`\`\`bash
git clone https://github.com/NoobKDH/lifehub.git
cd lifehub
npm install
\`\`\`

### 실행
\`\`\`bash
# 웹 개발 모드
npm start

# Electron 앱으로 실행
npm run electron:dev
\`\`\`

### 빌드
\`\`\`bash
# Windows 실행 파일 생성
npm run electron:build-win
\`\`\`

빌드된 파일은 `dist/` 폴더에 생성됩니다.
