# LifeHub 🌟

생산성 향상을 위한 올인원 데스크톱 애플리케이션

## ✨ 주요 기능

- 📝 **할 일 관리**: 우선순위, 카테고리별 분류
- 🎯 **습관 트래커**: 일일 습관 체크 및 연속 일수 기록
- 📅 **일정 관리**: 월/주/일 뷰, 반복 일정 설정
- 📄 **메모**: 태그를 활용한 메모 작성
- 🌓 **다크/라이트 모드**
- 💾 **자동 저장**

## 🚀 시작하기

### 필수 요구사항
- Node.js 18 이상

### 설치
bash
git clone https://github.com/yourusername/lifehub.git
cd lifehub
npm install


### 실행
bash
# 웹 개발 모드
npm start

# Electron 앱으로 실행
npm run electron:dev


### 빌드
bash
# Windows 실행 파일 생성
npm run electron:build-win
